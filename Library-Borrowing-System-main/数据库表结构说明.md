# 数据库表结构说明

该系统使用 MySQL 数据库，通过 JPA (Hibernate) 自动建表，共 3 张表。

---

## 1. t_user — 用户表

| 字段 | 类型 | 约束 | 说明 |
|------|------|------|------|
| id | BIGINT | PK, 自增 | 用户ID |
| username | VARCHAR(50) | NOT NULL, UNIQUE | 用户名 |
| password | VARCHAR(100) | NOT NULL | 密码(BCrypt加密) |
| email | VARCHAR(255) | - | 邮箱 |
| phone_number | VARCHAR(11) | NOT NULL, UNIQUE | 手机号 |
| role | VARCHAR(枚举) | NOT NULL | 角色: `USER` / `ADMIN` |
| create_time | DATETIME | - | 创建时间(自动填充) |

### 默认用户

| 用户名 | 密码 | 角色 | 手机号 |
|--------|------|------|--------|
| admin | admin123 | ADMIN | 13800138000 |
| user | user123 | USER | 13800138001 |

## 3. t_borrow_record — 借阅记录表

| 字段 | 类型 | 约束 | 说明 |
|------|------|------|------|
| id | BIGINT | PK, 自增 | 记录ID |
| book_id | BIGINT | NOT NULL | 图书ID(关联t_book) |
| user_id | BIGINT | NOT NULL | 用户ID(关联t_user) |
| borrow_time | DATETIME | NOT NULL | 借阅时间(自动填充) |
| due_time | DATETIME | NOT NULL | 应还时间(默认借阅日起14天) |
| return_time | DATETIME | - | 实际归还时间 |
| renew_count | INT | NOT NULL | 续借次数(默认0) |
| status | VARCHAR(枚举) | NOT NULL | 状态: `BORROWED` / `RETURNED` / `OVERDUE` |

---

## 建表方式

由 JPA (Hibernate) 自动创建，配置在 `application.yml`：

```yaml
spring:
  jpa:
    hibernate:
      ddl-auto: update
```

---

## 外键关系

```
t_user.id  ←──  t_borrow_record.user_id   (多对一)
t_book.id  ←──  t_borrow_record.book_id   (多对一)
```
